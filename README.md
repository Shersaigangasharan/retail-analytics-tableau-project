## 📘 Project Overview
This project transforms retail data into strategic business insights using Tableau.  
It was developed as part of the MSc Data Analytics programme at BSBI, following the UCA academic standards.

The analysis focuses on:
- Customer behaviour  
- Product profitability  
- Regional performance  
- Operational efficiency  
- Strategic decision-making  

The project includes:
- Three interactive Tableau dashboards  
- A seven‑point Tableau Story   
- Supporting worksheets and KPIs  

---

## 📊 Dashboards Included
### 1. **Executive Overview Dashboard**
Shows total sales, profit, KPIs, segment comparison, and monthly trends.

### 2. **Customer & Product Performance Dashboard**
Highlights category performance, sub‑category profitability, segment behaviour, and weak products.

### 3. **Regional & Operational Insights Dashboard**
Displays geographical sales distribution, return risks, and shipping efficiency.

---

## 📚 Tableau Story
A structured seven‑point narrative covering:
1. Business problem  
2. Executive insights  
3. Category performance  
4. Regional trends  
5. Return analysis  
6. Shipping performance  
7. Strategic recommendations
